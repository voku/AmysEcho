## Agent Task Brief
Goal: in the caregiver area a caregiver picks an image file (PNG, JPEG, WebP, SVG rasterised) for any concept on a board (catalogue, custom or retired), sees a preview, saves it, can replace it and go back to the app's picture. The image is downscaled on the device and stored in the profile as its own data entry, so the profile backup carries it; nothing is uploaded. The child's board and the recognise view show the profile's picture before the catalogue's. Scope: src/board-data.ts, src/caregiver.ts, public/index.html (CSP img-src data:), public/styles.css, public/sw.js, tests, docs/storage.md, docs/caregiver.md, docs/assets.md.
