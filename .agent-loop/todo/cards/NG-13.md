## Agent Task Brief
Goal: child view and caregiver area are separate; entering the caregiver area needs a deliberate action that a small child is unlikely to perform by accident, without passwords that lock a carer out. Destructive actions (delete profile) ask again and say what is lost and that exported copies are not recalled. German text throughout. Scope: src/, public/, test/. Depends on: NG-2. Product contract section 6. From the NG-2 reviews: exportedAt is validated but not kept and profiles have no modified time, so the UI cannot warn that a backup is older than what is stored before a replace; a copy yields two profiles with the same name. Tell carers that deletion is logical and the browser may keep remnants on disk for a while. From the NG-25 reviews: damaged profiles carry kind unsupported-version or unreadable; never offer deletion for unsupported-version, and do not call usage() on such entries because it writes. An unreadable profile may hold intact data (for example a name with a now-forbidden invisible character, or one that NFC lengthens past 40 code points): offer repair by rename or a salvage export before deletion. getActive returning null together with damaged entries must not start the create-profile flow. Names: invisible characters outside category Cf (U+3164, U+115F, U+2800, variation selectors alone) and joiners between Latin letters are accepted, so add a confusable or duplicate-name check; pasted names carrying RLM, soft hyphen, zero-width space or BOM are rejected with a generic English error, so strip them or explain in German. Size errors need German wording that says to delete entries when the profile is already over the limit.
