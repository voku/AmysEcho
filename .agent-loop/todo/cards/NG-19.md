## Agent Task Brief
Goal: gesture examples are stored per profile as a versioned record (profile id, concept id, capture time, extraction version, anchor, features stored unweighted or with their extraction parameters), included in export/restore and removed completely on profile delete. Incompatible versions are rejected, never guessed. Decide and document whether raw landmarks are kept on the device to allow re-extraction; if yes, say so in the caregiver area. Scope: src/recognition/, src/profiles/, test/, docs/storage.md, docs/recognition.md. Depends on: NG-2. NG-8 item 5, product contract section 3.
