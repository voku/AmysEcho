## Agent Task Brief
Goal: a child taps start and makes a gesture; the app shows what it understood and speaks only after confirmation (by the child or the carer, as the profile is set). Unknown shows up to three candidates and the board. Choosing a candidate can be saved as a new example in the caregiver flow; the last spoken message can be cancelled; the same gesture is not spoken twice within a cooldown. Nothing is spoken on unknown. Scope: src/recognise/, src/board.ts, test/. Depends on: NG-4. Issue 1176 slice S3.
