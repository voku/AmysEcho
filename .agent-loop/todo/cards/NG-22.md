- **Summary:** Browser storage can be evicted and writes can be interrupted. A family must not lose taught gestures silently.

## Agent Task Brief
Goal: the app asks for persistent storage where the browser offers it and shows the result; a corrupt or partly written profile is detected at start and reported with a restore path instead of crashing or showing an empty board; multi-step writes are atomic; the caregiver area shows when the last backup was exported. Scope: src/profiles/, test/, docs/storage.md. Depends on: NG-2, NG-19. Issue 1176 slice S5. From the NG-2 reviews: an unknown storage schema makes the store refuse to open and leaves a family with no export path; a layout change needs a migration or a read-only export for old layouts before it ships, and a stale cached app after an update fails the same way. Two tabs or an installed app plus a tab are not coordinated (data.set racing remove can leave an orphan key); use Web Locks or a transactional read.
