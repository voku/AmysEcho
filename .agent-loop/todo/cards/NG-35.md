## Agent Task Brief
Goal: the area names damaged profiles and concepts and offers the safe repair for each kind. Scope: src/caregiver.ts, test/caregiver.test.mjs, docs/caregiver.md, docs/storage.md; a change to src/profiles/ only if a typed read of the damage kind is missing. Rules from earlier reviews: damaged profiles carry kind unsupported-version or unreadable; never offer deletion for unsupported-version and do not call usage() on such entries because it writes; an unreadable profile may hold intact data (a name with a now-forbidden invisible character, or one NFC lengthens past 40 code points), so offer repair by rename or a salvage export before deletion; a damaged entry whose name is not a valid concept id can only be removed through store.data(id).delete; keep the slot of a concept that could not be loaded visible so the learned layout does not shift (decide with the board, docs/board.md); a lost storage schema marker needs its own message; a persistent problem can hide behind a working examples board for days, so leave a trace the caregiver sees on next opening.
