# Amy First Checklist

Use this quick checklist before merge:

- Confirm the change improves communication reliability, clarity, safety, or maintainability.
- Confirm no interruption risk was introduced for gesture recognition or message output.
- Confirm user-facing text remains child/caregiver appropriate and in German.
- Confirm tests were run and failures were investigated (not ignored).
- Confirm docs were updated when process/behavior changed.
